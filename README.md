# 雁城零工

面向衡阳本地零工市场的一站式招聘服务小程序，涵盖**微信小程序（求职端）**、**Web 管理后台（运营端）**、**Node.js 后端（服务端）** 三端。

> 项目采用 Vibe Coding（AI 辅助编程）模式独立完成需求设计、开发、联调与真机测试。

## 功能特性

### 小程序端（求职者）
- 🏠 **首页岗位推荐**：仅展示平台审核发布的岗位
- 🔍 **找零工**：岗位分类浏览、关键词搜索、区域筛选
- 📋 **岗位详情与投递**：一键投递、收藏岗位
- 📢 **便民信息**：用户自行发布 UGC 信息（房屋租赁、二手交易、商业宣传等），支持图片上传、地理定位
- 💬 **在线客服**：与平台客服实时会话
- 🔔 **消息通知**：投递状态、审核结果通知
- 👤 **个人中心**：微信一键登录（头像昵称合规获取）、手机号登录、我的发布/投递/收藏

### 管理后台（运营端）
- 岗位发布与审核（待审 / 已发布 / 驳回 / 下线 状态机）
- 便民信息治理与举报处置
- 用户管理、投递记录查看、数据导出
- 客服会话回复

### 后端
- 30+ RESTful 接口：登录鉴权、内容 CRUD、文件上传、会话消息
- 双数据流内容架构：平台自营岗位（`jobs`）与用户 UGC（`convenience_posts`）物理隔离
- 数据规范化层：薪资格式归一、图片相对路径存储 + 运行时动态拼接
- 系统通知幂等去重、utf8mb4 全链路编码

## 技术栈

| 端 | 技术 |
|---|---|
| 小程序 | 微信小程序原生框架（WXML / WXSS / JS） |
| 管理后台 | HTML / CSS / JavaScript（原生，无框架依赖） |
| 后端 | Node.js · Express · Multer · mysql2 |
| 数据库 | MySQL（utf8mb4） |
| 测试 | Node.js 内置 test runner（9 个自动化测试用例） |

## 快速开始

### 1. 初始化数据库

```bash
mysql -u root -p < 雁城零工_管理员平台/sql/yancheng_lingong.sql
```

### 2. 配置并启动后端

```bash
cd 雁城零工_管理员平台/server
npm install
cp .env.example .env        # 按实际环境修改数据库密码等配置
node server.js              # 默认监听 http://127.0.0.1:3000
```

> ⚠️ `.env` 中需填入你的 MySQL 密码；如需手机号一键登录，还需在微信公众平台获取 `WX_APPID` / `WX_SECRET`。

### 3. 启动小程序

1. 用微信开发者工具导入 `雁城零工_修复版` 目录
2. 在 `utils/api.js` 中将 `API_BASE` 改为你电脑的局域网 IP
3. 编译运行；真机调试时手机与电脑需在同一 WiFi

### 4. 访问管理后台

浏览器打开 `雁城零工_管理员平台/index.html`，使用 `.env` 中配置的管理员账号登录。

## 运行测试

```bash
cd 雁城零工_修复版/tests
node --test
```

## 安全说明

- `.env`（含数据库密码、微信密钥）已被 `.gitignore` 排除，不会提交到仓库
- 图片等用户上传文件存于 `server/uploads/`，同样不入库
- 生产部署请务必：修改默认管理员密码、启用 HTTPS、在微信公众平台配置合法域名
